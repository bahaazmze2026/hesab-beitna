# حساب بيتنا

تطبيق Android عربي محلي لإدارة دخل ومصروفات البيت، بأرقام `123` وعملة الجنيه المصري، ودورة مالية تبدأ من يوم الراتب. الهاتف المستهدف Samsung S25 Ultra، مع حد أدنى Android 8 / API 26.

**معاينة 1.3.0 تضيف مساعد البيت المالي**: أربعة تبويبات للتحليلات، رسوم تفاعلية وتفاصيل العمليات، أسباب تغير الصرف، محاكي توفير وخطة للدورة القادمة. تحتفظ بهوية القطة، واختيار Light/Dark المستقل عن الهاتف، والجلاس وشبكة الأصناف.

نجحت 23 حالة اختبار وحدة محليًا، منها 14 للتحليل، ويجري التحقق من تدفقات الواجهة الجديدة على GitHub Actions. لا تُعتبر معاينة موقعة بمفتاح المالك. تفاصيل المنهج والقيود في [دليل التحليلات](docs/analytics-guide.md) و[تقرير الهوية والتحقق](docs/brand-verification.md).

نسخة debug تستخدم `com.hesabbeitna.app.preview` وتُثبّت بجانب التطبيق الحالي. نسخة release تحتفظ بمعرّف التطبيق الأصلي، وتحتاج مفتاح المالك المتاح لدى صاحب المشروع. لا تحتوي الحزمة التجريبية على بيانات فعلية أو مفاتيح المالك.

راجع [قواعد الهوية](docs/brand-identity.md)، [خطة التنفيذ وحصر الشاشات](docs/implementation-plan.md)، و[دليل الاستخدام](docs/USER-GUIDE.md).

## الموجود في الكود

- إعداد يوم الراتب وتاريخ بدء المتابعة والرصيد الافتتاحي.
- دخل، مصروف، تحويل، رسوم تحويل مستقلة، واسترداد مرتبط بمصروف.
- حسابات ومحافظ، تعديل وأرشفة، وأرصدة مشتقة من الحركات.
- تصنيفات دخل ومصروف قابلة للتسمية والأرشفة.
- بحث وتصفية وتعديل وحذف مع حماية روابط الاسترداد.
- ميزانية البيت وميزانيات البنود، تجاوزات، ونسخ الميزانيات الناقصة للدورة التالية.
- فواتير وأقساط دورية، استحقاقات بمعرفات ثابتة، سداد جزئي، تعديل مبلغ استحقاق محدد، وتعديل وإيقاف التكرار المستقبلي.
- ترتيب بالمبلغ وبالعدد، مقارنة بأيام متساوية، متوسط يومي، توزيع زمني، وتوقع محدود الثقة.
- توصيات محلية مفسرة، وهدف ادخار مرتبط بحساب مخصص.
- قفل بالبصمة أو قفل الهاتف، ومنع لقطات الشاشة.
- بيانات محلية مشفرة، نسخ احتياطي مشفر بكلمة مرور، واستعادة باستبدال كامل مع نسخة أمان محلية.
- تصدير CSV يدعم العربية ويحمي من حقن صيغ جداول البيانات، وتقرير PDF.
- تذكير دوري تقريبي بالفواتير، دون تفاصيل مالية في إشعار شاشة القفل.
- لا يوجد إذن إنترنت في ملف manifest المصدر، ولا خادم أو مزامنة أو اتصال ببنوك.

لا تُضاف بيانات تجريبية إلى الحساب الحقيقي.

## البناء

راجع [تعليمات البناء والتوقيع](docs/BUILD.md). تحتاج JDK 17، Gradle 8.9، Android SDK Platform 35 وBuild Tools 35.0.0، واتصالًا لتنزيل الاعتماديات في أول بناء.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

المسار المتوقع بعد نجاح البناء:

```text
app/build/outputs/apk/debug/app-debug.apk
```

هذا APK تجريبي موقع بمفتاح debug، وليس إصدار release بمفتاح المالك.

بعد إنشاء `signing.properties` وفق التعليمات:

```sh
./gradlew testDebugUnitTest lintDebug assembleRelease
```

## فحوص يمكن تشغيلها دون Android SDK

```sh
bash tools/check-finance.sh
```

تستخدم هذه الفحوص نفس كود Java الذي يستدعيه التطبيق للحسابات وتشفير النسخ الاحتياطية. نجح تشغيلها في البيئة الحالية. لا تثبت نجاح بناء Kotlin أو Room أو Compose ولا تجربة الهاتف.

التفاصيل في [تقرير التحقق الحالي](docs/brand-verification.md) و[قواعد البيانات والحساب](docs/DATA.md).

## البناء الآلي

ملف `.github/workflows/android.yml` يبني التطبيق ويشغل اختبارات الوحدات وlint واختبارات محاكي Android 15. [البناء الناجح](https://github.com/bahaazmze2026/hesab-beitna/actions/runs/36982767432) استخدم مصدر التطبيق `269e1d6c9460e39ba8ba84713ce0342d780ccfab`.

بُني release النهائي في هذا المسار ثم وُقّع محليًا بمفتاح المالك الأصلي. لتوقيع تحديثات آليًا أضف أسرار التوقيع وفق BUILD.md؛ دونها يكون release الآلي غير موقع. إنشاء مفتاح جديد تلقائيًا معطل بعد استلام مفتاح المالك.

## حدود النسخة

- شخص واحد وهاتف واحد وعملة واحدة؛ لا مزامنة ولا مشاركة.
- الأقساط التزامات دورية، وليست محرك قروض أو فوائد.
- الاستعادة استبدال كامل وليست دمجًا.
- الأرصدة الافتتاحية لكل الحسابات تُنسب إلى تاريخ بدء المتابعة نفسه.
- تغيير يوم الراتب يعيد تجميع التقارير؛ الميزانيات القديمة تبقى مرتبطة بتواريخ بدايتها ولا تُنقل تلقائيًا.
- الرسوم عملية مستقلة؛ تعديل أو حذف التحويل لاحقًا لا يعدل الرسوم تلقائيًا.
- التوقع لا يظهر قبل 7 أيام مغطاة وبوجود مصروف فعلي مسجل، ولا يمثل نتيجة فعلية.
- حد حجم البيانات/النسخة 32 MiB؛ الحد العددي للعمليات 100,000 لا يُعد ضمان أداء على الهاتف.
- جميع البيانات تُقرأ إلى الذاكرة والتحليلات محلية. يلزم قياس الأداء على الجهاز قبل اعتماد حدود الاستخدام الكبيرة.
