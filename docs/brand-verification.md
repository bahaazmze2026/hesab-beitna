- الصورة المرفقة هي مصدر الأيقونة؛ موارد launcher التقليدية والتكيفية والدائرية وmonochrome وبداية النظام محدثة. معاينة تقنية للأقنعة في `qa/launcher-masks.png`، وليست لقطة تشغيل للتطبيق.
- ملفات الحسابات والتخزين والتشفير والنماذج الأساسية `Finance.java` و`BackupCrypto.java` و`Storage.kt` و`AppModel.kt` و`Models.kt` دون تعديل. لم تُضف ترحيلات قاعدة بيانات أو بيانات مالية تجريبية إلى المنتج.

## ما تعذّر اختباره
المحاكي لم يصل إلى حالة تشغيل تسمح بفتح التطبيق في هذه البيئة. جرت محاولات صور API 35 وAPI 26 دون تسريع KVM، مع انتهاء مهلة الإقلاع أو إعادة تشغيل النظام. أُوقفت المحاولات لتجنب تأخير التسليم أكثر. محاولة بديلة للتصيير المحلي لم تكتمل؛ حُذفت اعتمادياتها التجريبية قبل البناء النهائي.

لذلك لم تُنفذ اختبارات إضافة/تعديل المعاملات والبحث والتصفية والتحليلات عبر الواجهة الجديدة، ولم تُراجع الشاشات أثناء التشغيل. العربية وتكبير الخط والشاشة الصغيرة ولوحة المفاتيح والوضع الداكن والمبالغ الكبيرة والأداء وTalkBack تبقى اختبارات تشغيل مطلوبة. فحص التباين حسابي للألوان المحددة؛ لا يثبت عدم القص أو التداخل أثناء العرض. لا توجد لقطات للشاشات الرئيسية تُسلّم بوصفها دليل تشغيل.

اختبارات `UiSmokeTest.kt` المعدلة تُجمّع بنجاح وتغطي الإضافة والتحقق والتعديل والبحث والفترة والتحليلات والمسودات والمبالغ الطويلة. إعداد GitHub Actions جاهز لتشغيلها بمحاكي متسارع والتقاط الصور بعد نشر الفرع، لكن لم يُشغّل هذا المسار على التعديلات هنا.

## تصحيح ظهور الهوية

استبدل شريط العنوان الثابت بترويسة مرنة تعرض القطة واسم حساب بيتنا فوق جميع الشاشات الرئيسية؛ تظهر التسمية أيضًا في شاشة القفل. تعرض بطاقة ملخص الدورة مبالغ الدخل والمصروف في عمودين، وتتحول إلى ترتيب رأسي عند تكبير الخط أو ضيق الشاشة. أصبح زر إضافة المصروف واحدًا في الصفحة الرئيسية. أضيف تحقق آلي من ظهور الاسم، وتستمر لقطات الاختبار على تثبيت المعاينة المعزول فقط.

اختبارات المحاكي والمراجعة البصرية النهائية مطلوبة قبل اعتماد APK النهائي، والتوقيع يجب أن يستخدم مفتاح المالك الأصلي.

- اختيار فاتح/داكن/حسب الهاتف يُحفظ محليًا ويطبق فورًا؛ لا يغيّر السجل المالي أو تنسيق النسخ الاحتياطية.

نتيجة تشغيل GitHub Actions رقم 9: نجح اختبار حفظ الثيم وتشغيل وإيقاف الجلاس بعد إعادة إنشاء Activity، وإنشاء صنف برمز وتسجيل مصروف 12.50 عليه. نجح اختبار الأرقام الكبيرة والمسودة، واختبارا التخزين. توقف اختبار التنقل عند رابط الحسابات بعد التمرير، ولذلك لا تُعتمد المجموعة كاملة بعد. عُدّل الاختبار لتفعيل روابط التنقل بإجراء الوصول المباشر، وانتظار رسم النوافذ بعد رفع الحماية داخل الاختبار فقط لتجنب لقطات سوداء؛ حماية نسخة التطبيق لم تتغير.
