# Mew / Meow Budget 1.7.0 layout review

The available-money headline and next action should be understandable at a glance. The supplied cat, ivory/green/orange identity, RTL, local encryption and all financial calculations remain unchanged.

| Screen / flow | Before | Implemented |
| --- | --- | --- |
| Home | Header, slogan, period, page subtitle and mascot message precede an oversized hero; actions and equally weighted cards compete | Shorter header; compact available-money hero; separate calm expense/income metrics; budget before secondary tools; complete financial values fit available width, with vertical metrics for long amounts |
| Main navigation | FAB overlaps the scroll viewport; quick expense requires choosing an action first | Compact 48 dp minimum navigation items; expense and other operations dock outside content; expense opens directly |
| Expense / income / transfer / edit / payment | Tall operation grid; optional template step on the primary path; save scrolls out of view | Compact type chips; optional details grouped; save stays above the keyboard; explicit saving/validation states |
| Transactions | Filtered empty state gives no reset action; generous card/gap spacing | Reset filters action; shared compact card and page spacing |
| Budget | Editor appears before the overall financial position | Main remaining-budget summary and progress lead the editor |
| Analytics | Two permanent rows of tab cards reduce the working viewport; all summary amounts have similar emphasis | Single 48 dp minimum horizontally scrolling tab strip; separate expense/income cards and surplus |
| Monthly planning | Every allocation looks like a main headline | Income leads, allocations use compact detail amounts; shared card rhythm |
| Calendar, templates, accounts, dues | Repeated large surfaces and trailing FAB clearance | Consistent compact surfaces; archive/default controls wrap; obsolete bottom clearance removed; calendar days retain 48 dp width with horizontal scrolling on small screens |
| More / search / settings / onboarding / other dialogs | Large grid tiles and inconsistent spacing | Shared restrained glass and 16 dp spacing; responsive single-column tools at narrow widths or large fonts; keyboard Next actions |
| Categories | Selecting a tile adds a line and changes its height | Selection line reserves its height; large fonts use wider grid columns |
| Persistence and privacy | Existing encrypted local data and preview certificate | No schema, calculation, package, permission or signing changes; versionCode 12 |

## Validation protocol

- Local independent Java finance, authenticated-backup and date/accounting invariants.
- Hosted Android compiler, unit tests, lint and API 35 native UI suites.
- Same-device before/after screenshots from the actual delivered 1.6.3 APK and final 1.7.0 APK, using the same synthetic ledger.
- Install the actual 1.6.3 baseline, seed encrypted ledger, plan, template and appearance, then `adb install -r` the final version and verify exact persistence.
- 320 dp screen, fontScale 1.5: dock/nav touch targets, no viewport overlap, one-tap expense entry, keyboard/save, transactions, analytics and dark amount layout.

Actual results, APK checksum, links and limitations are added after native execution. No real user ledger is used by QA. Test captures temporarily clear screenshot protection only in the isolated instrumented preview installation; the production application keeps FLAG_SECURE.
