## Validation protocol

- Local independent Java finance, authenticated-backup and date/accounting invariants.
- Hosted Android compiler, unit tests, lint and API 35 native UI suites.
- Same-device before/after screenshots from the actual delivered 1.6.3 APK and final 1.7.0 APK, using the same synthetic ledger.
- Install the actual 1.6.3 baseline, seed encrypted ledger, plan, template and appearance, then `adb install -r` the final version and verify exact persistence.
- 320 dp screen, fontScale 1.5: dock/nav touch targets, no viewport overlap, one-tap expense entry, keyboard/save, transactions, analytics and dark amount layout.

No real user ledger is used by QA. Test captures temporarily clear screenshot protection only in the isolated instrumented preview installation; the production application keeps FLAG_SECURE.
