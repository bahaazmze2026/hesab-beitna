# تقرير التحقق

## ما نُفذ فعلًا في البيئة

نجح تشغيل `tools/check-finance.sh` باستخدام وحدة مترجم Java الموجودة في Java 21، رغم عدم وجود مشغل javac مستقل في PATH:

```text
PASS: 34 independent financial acceptance checks
PASS: 13 authenticated backup acceptance checks
PASS: 3577 date and accounting invariants
```

إجمالي 3,624 فحصًا؛ العدد الكبير يتضمن تكرار خصائص الدورة والمحاسبة عبر حالات متعددة، وليس 3,624 ميزة مختلفة.

- الأرصدة، التحويلات، الرسوم، والاستردادات.
- الفرق بين ترتيب المبلغ وعدد العمليات.
- المقارنة المتساوية، القيم الصفرية، ودورة الراتب وأطوال الأشهر والسنة الكبيسة.
- التوقع مع استبعاد سداد الفواتير من الوتيرة، وعدم التوقع عند نقص البيانات.
- حفظ وفك تشفير النسخ، عشوائية النسخ، رفض كلمة مرور خاطئة والعبث والرأس غير الصحيح والاقتطاع.
- استعادة بيانات ثنائية كبيرة نسبيًا داخل محرك التشفير.
- تطابق مجموع أرصدة الحسابات مع الافتتاحي + الدخل − صافي المصروفات عبر سيناريوهات مولدة ببذرة ثابتة.

كذلك فُحصت صياغة موارد XML وملف workflow ومشغل shell. هذه فحوص صياغة، وليست تجميع Android.

## المكتوب ولم يُشغّل

- `HouseholdTest.kt`: علاقات البيانات ومنع التكرار والسداد الجزئي والأرشفة ونسخ كامل النموذج وCSV.
- `RepositoryTest.kt`: تخزين مشفر، فتح المستودع مجددًا، وعدم استبدال البيانات عند فشل التحقق.
- GitHub Actions: مسار بناء debug واختبارات Kotlin وlint، وrelease إذا توفرت مفاتيح المالك.

## غير متحقق منه

لم تتوفر Android SDK أو Gradle أو مترجم Kotlin في البيئة، وتعذر تنزيلها. لذلك لم يُتحقق من:

- تجميع Kotlin/Compose/Room أو حل الاعتماديات.
- إنتاج APK أو توقيعه.
- تشغيل الواجهات أو التثبيت على S25 Ultra.
- القفل الحقيقي وإدارة دورة حياة Android وإشعارات WorkManager.
- ملفات CSV/PDF من التطبيق والاستعادة عبر منتقي الملفات على هاتفين.
- manifest المدمج، وسرعة آلاف السجلات على الهاتف، واستهلاك الذاكرة.

## حالات قبول للهاتف قبل الإصدار

1. افتتاحي 1,000 + دخل 5,000 − مصروف 1,200 − تحويل 500: النقد 4,300 والمحفظة 500؛ إجمالي المصروف 1,200.
2. رسوم تحويل 10: انخفاض مجموع الأرصدة 10 وزيادة المصروف 10 فقط.
3. مصروف 1,000 ثم استرداد 200: صافي المصروف 800، والدخل لا يتغير.
4. فاتورة مخططة 900 ثم سداد 400: الفعلي 400 والمتبقي 500؛ لا تُدفع مرتين عند الضغط المزدوج.
5. ميزانية 1,000 وصرف 1,250: تجاوز 250 و25%.
6. إعادة فتح التطبيق وتدوير الهاتف وإيقافه أثناء الحفظ: لا قيد جزئي ولا فقد بيانات محفوظة.
7. نسخ ثم استعادة على تثبيت جديد: تطابق الحسابات والعمليات والاستحقاقات والميزانيات.
8. ملف تالف أو كلمة خاطئة: لا تغيير للبيانات، والرجوع قبل آخر استعادة يعمل.
9. RTL وأرقام 123 وخط كبير وشاشة صغيرة: لا قص للمبالغ أو تعطيل أزرار الحفظ.
10. العمل دون شبكة ورفض إذن الإشعار: التسجيل والتحليل والاستحقاقات تظل متاحة.
11. استعادة ثم سداد قسط أو تعديل مصروف مرتبط باسترداد: سلامة العلاقات واستمرار دقة الرصيد.
12. تحديث APK بنفس مفتاح التوقيع: بقاء البيانات والقفل والنسخ سليمة.
