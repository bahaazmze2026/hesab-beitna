# استلام مفتاح توقيع المالك

أول إصدار release يمكن توقيعه بمفتاح مولد مرة واحدة بعد نجاح الاختبارات، دون وضع المفتاح أو كلمة مروره في الكود العام.

- `tools/signing-recovery-public.pem` هو مفتاح RSA **عام** فقط.
- المفتاح الخاص للاسترجاع يبقى خارج المستودع داخل مساحة العمل الخاصة بالمالك.
- ينشئ مسار البناء PKCS12 بكلمة مرور عشوائية 256-bit، ويشفر كلمة المرور RSA-OAEP باستخدام SHA-256 والمفتاح العام.
- ملف البناء المشفر يحتوي `owner.jks` و`owner-password.rsa` فقط. كلمة المرور غير المشفرة لا تدخل artifact أو الكود.
- بعد تنزيل الملف، يفك المالك كلمة المرور باستخدام مفتاح الاسترجاع الخاص:

```sh
openssl pkeyutl -decrypt -inkey recovery-private.pem \
  -pkeyopt rsa_padding_mode:oaep -pkeyopt rsa_oaep_md:sha256 \
  -pkeyopt rsa_mgf1_md:sha256 -in owner-password.rsa -out owner-password.txt
```

ملف `owner-password.txt` حساس، ولا يُرفع إلى Git أو يُنشر. احتفظ بالـkeystore وكلمة المرور في مكان خاص خارج الهاتف؛ يحتاجهما كل تحديث للتطبيق.

التوليد الأولي يُعطل بعد تسليم المفتاح بنجاح لمنع تغيير هوية توقيع التطبيق في بناء لاحق. تُستخدم بعدها أسرار GitHub الأربعة الموضحة في BUILD.md أو التوقيع المحلي بمفتاح المالك المستلم.
