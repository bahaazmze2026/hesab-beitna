# خطة التنفيذ والحصر
1. فحص Kotlin/Compose، ملفات الشاشات والنماذج، Room/التشفير، wrapper والتوقيع. نقطة البداية daab9b3، لا تعديلات محلية سابقة، فرع feat/cat-wallet-identity.
2. بناء نظام التصميم المركزي والخط والأيقونات والبداية؛ إعادة تنظيم التنقل وملخص الرئيسية؛ تطبيق المكونات على جميع الواجهات والنوافذ المذكورة في brand-identity.md.
3. تحسين عرض المبالغ الطويلة واختيار الفئات والتحقق وحفظ مسودات الحقول عند إعادة إنشاء Activity. الاحتفاظ بجميع الوظائف المالية وبنية البيانات.
4. تشغيل فحوص Java، فحوص الموارد، اختبار contrast، ثم Android compile/unit/lint، ومحاكي للتدفقات والصور وحالات الوصول.
5. مراجعة الصور وإصلاح المشاكل، تجهيز debug APK وتوثيق أدلة الاختبار والقيود. مفاتيح المالك لا تُنشأ أو تُستبدل.

مقترحات منفصلة خارج هذا التعديل: منتقي تاريخ تقويمي بدل صيغة الإدخال الحالية، دعم حسابات متعددة المستخدمين، قياس الأداء ببيانات ضخمة على جهاز المستخدم. لا ينفذ أي منها في هذه الهوية.
